# Relationship

## Definition

A semantic assertion connecting two or more objects.

Relationships are not containers; they are facts.

They answer:
> "How are these things connected?"

## Examples
- derives from
- summarizes
- references
- duplicates
- depends on
- caused by
- fulfills
- contradicts
- attached to
- discussed in
- created during
- assigned during
- about

## Relationships may be created by:
- AI
- imports
- user
- automation

## Intrinsic properties
- Type
- Confidence
- Provenance
- Creation time
