# Artifact

## Definition

A physical piece of captured data.

Artifacts are immutable evidence. They exist because they were created or imported from somewhere.

They answer:
> "What raw thing do I have?"

## Examples
- PDF
- Screenshot
- Photo
- Voice recording
- Video
- Source code file
- Markdown file
- Email export
- Calendar ICS
- Spreadsheet

## Not artifacts
- The meaning of a lecture.
- A homework assignment.
- A summary.
- A task.
- "This photo is from chemistry."

Those are interpretations.
   
## Intrinsic properties
- Contents
- MIME/type
- File size
- Hash
- Created timestamp
- Modified timestamp
- Metadata from the source

Notice that none of these require AI.
