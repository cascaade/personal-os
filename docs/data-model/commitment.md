# Commitment

## Definition

A promise that reality expects something from you.

It answers:
> "What am I responsible for?"

Everything that requires your future attention is a commitment.

Not "tasks", "projects", or "events". Those are behaviors.

## Examples
- Homework
- Doctor appointment
- Robotics competition
- College application
- Essay
- Practice piano
- Buy groceries
- Finish project

Notice a concert you're attending is still a commitment.

You committed to being there.

## Not commitments
- Notes
- PDFs
- Facts
- Relationships

## Intrinsic properties
- Description
- Current state
- Completion
- Activation
- Importance
- Estimated effort
- Actual effort
- Temporal constraints

No "due date". That's a relationship to time.
